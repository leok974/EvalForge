# Aggregate Functions

Calculates a set of values and returns a single value.

## Common Functions
- `COUNT(*)`: Rows count
- `SUM(col)`: Sum of values
- `AVG(col)`: Average value
- `MIN(col)`: Minimum value
- `MAX(col)`: Maximum value

## Syntax
```sql
SELECT COUNT(*) FROM users;
```
