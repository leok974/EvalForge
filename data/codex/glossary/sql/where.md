# WHERE

Filters records that meet a specified condition.

## Syntax
```sql
SELECT * FROM users WHERE age > 18;
```

## Operators
- `=`, `!=`, `>`, `<`, `>=`
- `AND`, `OR`, `NOT`
- `IN`, `BETWEEN`, `LIKE`

## Gotchas
- Case sensitivity depends on the database collation.
