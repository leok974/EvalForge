# Determinism

## Definition
**Determinism** means getting consistent behavior across repeated runs. In practice, it means reducing randomness and ambiguity so the same prompt produces similar outputs.

## Tiny example
A prompt with a strict schema, fixed bullet count, and clear constraints tends to be more deterministic than “Write something helpful.”

## Common pitfall
People try to “force determinism” with vague words like “be precise.” The real driver is **structure + constraints**: schemas, examples, and explicit limits. Also avoid mixing multiple unrelated goals in one prompt.
