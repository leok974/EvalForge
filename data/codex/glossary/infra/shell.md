# Shell

## Definition
A **shell** is a command-line program that reads your commands and runs them. Popular shells on Linux include `bash` and `zsh`. The shell also manages environment variables and your current working directory.

## Tiny example
Running `ls` asks the shell to execute the `ls` program, printing directory contents.

## Common pitfall
If a command “is not found,” it may not be installed, or it may not be in your `PATH`. Check:
- spelling
- installation
- `echo $PATH`
