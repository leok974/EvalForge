# Monitoring & Logging

Observability practices for production systems.

## Monitoring
- **Metrics**: CPU, memory, requests/sec
- **Tools**: Prometheus, Grafana, Datadog

## Logging
- **Centralized logs**: ELK stack, Loki
- **Structured logging**: JSON format

## Best Practices
- Set up alerts
- Log errors and anomalies
- Monitor key metrics
