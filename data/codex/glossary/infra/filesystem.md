# Filesystem

## Definition
The **filesystem** is the tree of directories and files on disk. On Linux, it is rooted at `/`. Everything is addressed by paths like `/home/user/file.txt`.

## Tiny example
`/etc` contains system configuration files, while `/home` contains user home directories.

## Common pitfall
Linux is case-sensitive. `File.txt` and `file.txt` are different files. This is a common source of “file not found” errors.
