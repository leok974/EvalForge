# HTML Document Skeleton

The basic structure every HTML document must follow.

## Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Page Title</title>
</head>
<body>
    <!-- Content goes here -->
</body>
</html>
```

## Key Components

- **`<!DOCTYPE html>`**: Declares HTML5 document type
- **`<html>`**: Root element, contains all content
- **`<head>`**: Metadata section (not visible)
- **`<body>`**: Visible page content

## Best Practices

- Always include `lang` attribute on `<html>`
- Declare UTF-8 character encoding
- Provide meaningful `<title>` for SEO and accessibility
