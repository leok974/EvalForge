# string

## Definition
A string is text in JavaScript, written in quotes (`"..."`, `'...'`) or as a template string (`` `...${x}...` ``).

## Tiny example
```js
const name = "Ada";
const msg = `Hello, ${name}!`;
```

## Common pitfall
Forgetting quotes turns text into an invalid identifier and causes errors.
