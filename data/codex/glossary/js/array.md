# array

## Definition
An array is an ordered list of values. Arrays keep items in a sequence and are written with `[]`.

## Tiny example
```js
const nums = [1, 2, 3];
console.log(nums[0]); // 1
```

## Common pitfall
Arrays are zero-indexed: the first element is at index `0`, not `1`.
