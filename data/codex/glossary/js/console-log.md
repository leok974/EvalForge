# console.log

## Definition
`console.log(...)` prints values to the terminal so you can see what your program is doing.

## Tiny example
```js
console.log("Hello!");
console.log(2 + 2);
```

## Common pitfall
Logging is not the same as returning. `console.log` shows output to a human; `return` produces a value for other code.
