# Variables

In JavaScript, variables are containers for data.

## Declaration
We use `let`, `const`, or `var`.

```javascript
let count = 10; // Reassignable
const pi = 3.14; // Constant
```

## Best Practices
- Prefer `const` by default.
- Use `let` if you need to reassign.
- Avoid `var` (legacy).
