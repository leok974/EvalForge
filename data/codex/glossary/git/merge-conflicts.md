# Merge Conflicts

Occur when Git can't automatically merge changes.

## Resolving
1. Open conflicted files
2. Look for `<<<<<<<`, `=======`, `>>>>>>>`
3. Edit to keep desired changes
4. `git add` resolved files
5. `git commit`

## Prevention
- Pull frequently
- Communicate with team
