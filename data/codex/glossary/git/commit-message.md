# Commit Message

## Definition
A **commit message** is the short explanation attached to a commit. Good messages describe the intent: what changed and why.

## Tiny example
Good: “Add README setup instructions”
Bad: “update” / “changes”

## Common pitfall
Messages that are too vague make history hard to understand and debug. A simple pattern:
- Verb + object (“Add login endpoint”, “Fix typo in docs”)
