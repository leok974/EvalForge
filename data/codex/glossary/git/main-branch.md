# Main Branch

## Definition
The **main branch** is the primary baseline branch where stable work lands. Many repos use `main` as the default branch.

## Tiny example
A common workflow:
- branch off main → commit changes → merge back into main

## Common pitfall
Committing directly to main makes it harder to review and revert. Use branches for features and fixes so main stays stable and readable.
