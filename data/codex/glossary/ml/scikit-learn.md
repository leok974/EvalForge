# scikit-learn

Python library for machine learning.

## Core Features
- Classification
- Regression
- Clustering
- Preprocessing
- Model evaluation

## Consistent API
```python
model.fit(X_train, y_train)       # Train
predictions = model.predict(X_test)  # Predict
score = model.score(X_test, y_test) # Evaluate
```
