# NumPy

Fundamental library for numerical computing in Python.

## Core Features
- **ndarray**: N-dimensional array
- **Vectorization**: Fast operations on arrays
- **Broadcasting**: Operations on different shapes

## Example
```python
import numpy as np
arr = np.array([1, 2, 3, 4])
print(arr * 2)  # [2, 4, 6, 8]
```
