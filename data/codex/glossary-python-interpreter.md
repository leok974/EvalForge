# Python Interpreter

The **Python Interpreter** is a program that reads and executes your Python code line by line.

## How It Works

When you run a Python script:
1. The interpreter reads your `.py` file
2. Parses the code to check syntax
3. Executes instructions one by one

## Running Code

```bash
python mycode.py
```

## Interactive Mode

You can also use the interpreter interactively:

```python
>>> print("Hello")
Hello
```

## Key Points

- **Immediate Execution**: Python is interpreted, not compiled
- **Error Detection**: Syntax errors are caught before execution
- **REPL**: Read-Eval-Print-Loop for testing code snippets

## Common Interpreters

- **CPython**: The standard, reference implementation
- **PyPy**: Faster alternative with JIT compilation  
- **IPython**: Enhanced interactive shell
