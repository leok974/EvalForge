## Hint 1
Your `task()` function must be named exactly `task` and exported. The grader imports
it directly: `import { task } from './main.js'`.

## Hint 2
A function declaration looks like this:
```js
export function task() {
  // your code here
}
```
Make sure the function actually runs without throwing — even an empty body passes the
"Code runs without error" objective.
