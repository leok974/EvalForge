# Lore: The Relational Warp

"Data is rarely a single island," Professor Null explains, his fingers tracing the connections on a holographic map. "It is an archipelago. To understand the whole, you must build bridges between the islands. We call this the Relational Warp."

He points to the `orders` and `users` nodes. "Without the join, an order is just a number. With the join, it is a human story. Find the names behind the transactions."
