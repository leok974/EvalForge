# Hints: Mini OOP System

## Hint 1 — Concept
Start by defining the `Account` class and the `__init__` method. Remember to use `self.balance` to store the value on the instance.

## Hint 2 — Guided
In `withdraw`, make sure you are subtracting from the balance. You should also check if the balance is sufficient *before* subtracting.

## Hint 3 — The Solution
The test suite will create an instance of your class and call its methods. Ensure your method names match the briefing exactly (`deposit`, `withdraw`).
