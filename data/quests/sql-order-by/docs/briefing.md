# Briefing — The Printed Roster

The Archives are printing a roster to hand out at the city offices.

To make it readable, the roster must be grouped by city, and within each city, names must be alphabetized.

## Output contract
Return exactly these columns, in this order:

1) `city`
2) `name`

## Sorting rules
- Sort by `city` ascending
- Then sort by `name` ascending
