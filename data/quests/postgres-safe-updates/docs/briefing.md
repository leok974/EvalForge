# The Salary Bump

Bob just completed an intense cross-training initiative and HR has authorized a raise.

His current salary is 115000. It needs to be updated to `125000`.

Your objective:
1. Write the `UPDATE` query to change the `salary` to 125000 in the `employees` table.
2. Add a `WHERE` clause targeting Bob, so you don't accidentally update everyone.
3. Finish your script with a `SELECT` query returning Bob's row so the system can verify the mutation.

*Note: You are operating in a safe sandbox. If you make a mistake, structural overrides will roll back the change upon the next run.*
