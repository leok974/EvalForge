Kael wiped grease from his face as the loading spinner spun endlessly on the terminal panel.

"The database shard out in sector nine is still spooling up. It takes exactly half a second," he muttered.

"Why did the main diagnostic script fail then?" asked the intern.

"Because," Kael sighed, "the script expected the data to be there instantaneously. The universe isn't perfectly synchronous. If you don't teach your scripts to wait patiently for a visual confirmation, they'll trip over their own feet trying to access things that haven't materialized yet."
