# Hints: SQL Ignition

## Hint 1 — Concept
Use the [SELECT](glossary/sql/select) clause followed by the asterisk `*` to specify all columns.

## Hint 2 — Table Name
Don't forget the [FROM](glossary/sql/from) clause to tell the database which [table](glossary/sql/table) to query. The table name is `users`.

## Hint 3 — The Solution
Your query should be just two lines long:
```sql
SELECT * FROM users;
```
That's it!
