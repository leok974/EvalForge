# First Sparks

Your mission: print a rocket launch countdown followed by ignition.

The program must output four lines in this exact order:
`T-minus 3`, `T-minus 2`, `T-minus 1`, then `IGNITION`.

This quest teaches output sequencing — making sure your program prints things
in the right order, one item at a time. Every program you write from here will
depend on that discipline.

**Objective:** Print the countdown and IGNITION using a loop and `print()`.
