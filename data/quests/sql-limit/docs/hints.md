# Hints: The Top 3 Report

### Hint 1 — Where to add LIMIT?
`LIMIT` goes at the **very end** of the query, after `ORDER BY`.

### Hint 2 — Start by verifying the sort
You already filtered and sorted the right rows in the starter code. If you run the starter as-is, you should see all active products sorted by price.

### Hint 3 — Apply the trim
Add `LIMIT 3` to the very end of your query to return exactly three rows.
