# HTML Ignition: Page Skeleton

Edit `index.html`.

Requirements:
1) First line: `<!DOCTYPE html>`
2) `<html lang="en">`
3) `<head>` includes:
   - `<meta charset="utf-8">`
   - `<meta name="viewport" content="width=device-width, initial-scale=1">`
   - `<title>EvalForge HTML</title>`
4) `<main data-testid="app">Hello, Web</main>` exists in `<body>`.
