# Linear Regression — Fit + Predict (Closed Form)

Implement:
- `fit_linear_regression(X, y) -> (coef, intercept)`
- `predict_linear(X, coef, intercept) -> preds`

Where:
- X: numpy array (n, d)
- y: numpy array (n,)
- coef: numpy array (d,)
- intercept: float

Use a deterministic closed-form solution (pseudo-inverse is acceptable).
