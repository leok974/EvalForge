# Tutorial Refinement Rubric

## 1. Clarity
- [ ] **Outcome is specific**: Teaches a tangible skill (e.g., "Learn debugging" vs "Fix SyntaxErrors").
- [ ] **Concept in 30s**: Explained in plain English with one clear mental model.
- [ ] **Walkthrough matches UI**: Instructions align with the actual buttons and actions (Run vs Submit).

## 2. Correctness
- [ ] **Runnable Example**: The provided code example works and is idiomatic.
- [ ] **Relevant Terms**: 2-6 terms that are actually used in the text.
- [ ] **Valid Links**: All Codex references resolve to existing files.

## 3. Teaching Quality
- [ ] **Realistic Mistakes**: "Common Mistakes" section reflects actual errors players encounter in this specific quest.
- [ ] **Aligned Checks**: "Check Yourself" questions test the core concept.
- [ ] **No Magic Leaps**: Every step is explained; "just do X" is avoided without rationale.

## 4. Implementation Checks (Automated)
- [ ] **No TODOs**: Content should not contain placeholder text like "TODO" or "Add definition".
- [ ] **Structure**: Adheres to the standard 7-section template.
