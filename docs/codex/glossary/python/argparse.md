# Definition
A standard library module for parsing command-line arguments.

# Why It Matters
Allows scripts to accept inputs from the terminal, making them flexible.

# Minimal Example
```python
import argparse\nparser = argparse.ArgumentParser()
```

# Common Mistakes
* Forgetting to call `parse_args()`.

# In EvalForge
* Used in CLI-based quests.
