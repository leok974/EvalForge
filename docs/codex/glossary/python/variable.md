## Definition
A **variable** is a named location in memory used to store data. You can think of it as a labeled box where you can put a value and retrieve it later using its name.

## Usage
- Assign values using the `=` operator.
- Variable names should be descriptive (snake_case in Python).
- No need to declare types explicitily (dynamic typing).

## Example
```python
# Storing a string
message = "Hello World"

# Storing a number
count = 42

# Using the variable
print(message)
```

## Best Practices
- Use `snake_case` for variable names (`my_variable`, not `myVariable`).
- Choose meaningful names (`user_age` instead of `x`).
