# Definition
A block of code which only runs when it is called. You can pass data, known as parameters, into a function.

# Why It Matters
Functions allow you to reuse code, organize logic, and make programs modular.

# Minimal Example
```python
def my_function(name):
  print("Hello " + name)

my_function("Alice")
```

# Common Mistakes
* Forgetting the parentheses `()` when calling the function.
* Not returning a value when one is expected.
