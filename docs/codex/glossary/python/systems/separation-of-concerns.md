# Separation of Concerns

**Separation of Concerns (SoC)** is a design principle for separating a computer program into distinct sections such that each section addresses a separate concern.

## Key Benefits

- **Maintainability:** Changes to one part of the system (e.g., UI) don't break others (e.g., Database).
- **Reusability:** distinct components can be reused in other projects.
- **Collaboration:** Teams can work on different parts simultaneously.

## Examples

- **MVC (Model-View-Controller):** Separates data (Model), UI (View), and logic (Controller).
- **HTML/CSS/JS:** Separates structure, style, and behavior.
