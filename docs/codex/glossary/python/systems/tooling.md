# Internal Tooling

Internal Tooling refers to the custom software, CLI scripts, and infrastructure built specifically to empower a company's own engineering teams.

### Characteristics of Great Tooling
-   **Zero Friction**: One-command setups (e.g., `make setup` or `npm install`).
-   **Reliability**: Tools must be as stable as the production code they support.
-   **Narrow Scope**: Do one thing extremely well (the Unix philosophy).

### Common Examples
-   Database migration helpers.
-   Log aggregators and trace visualizers.
-   Custom linters or code generation scripts.

### Relevance in EvalForge
You build internal tools to solve specific engineering challenges, ensuring that scaling the team doesn't mean scaling the complexity of the workflow.
