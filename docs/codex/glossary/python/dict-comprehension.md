title: Dict Comprehension
---

# Definition
A concise way to create dictionaries.

# Why It Matters
More readable and faster than loops for simple transforms.

# Minimal Example
```python
{k: v*2 for k, v in data.items()}
```

# Common Mistakes
* Using it for complex logic (hard to read).

# In EvalForge
* Common in data transformation tasks.
