# SQL (Structured Query Language)

SQL is the standard language for dealing with Relational Databases. It is used to insert, search, update, and delete database records.

## Usage

SQL is used in almost every modern application that needs to store data persistently and query it efficiently.
```sql
SELECT 'Hello SQL';
```
