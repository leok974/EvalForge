# Variable Assignment

**Variable assignment** is the process of storing a value in a variable. In Python, this is done using the `=` operator.

## Syntax

```python
variable_name = value
```

## Examples

```python
# Assigning an integer
count = 10

# Assigning a string
message = "Hello, World!"

# Assigning the result of an expression
total = count * 5
```

## Best Practices

- Use descriptive names (e.g., `user_age` instead of `x`).
- Follow snake_case convention for variable names in Python.
