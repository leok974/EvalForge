# Hints — First Sparks

## Hint 1 (nudge)
This is almost always about **exact stdout**. Start by printing the minimum required lines.

## Hint 2 (more specific)
Look for a `main()` function or a “to-do” comment that tells you what to print.

## Hint 3 (close)
If output mismatches, compare your output to the expected format using a literal diff:
- check punctuation
- check spaces
- check line breaks
