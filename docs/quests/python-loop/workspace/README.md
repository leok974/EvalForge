# Loop

## Objective
Use a loop and a conditional to print **all even numbers** from **1 to 10 (inclusive)**,
then print the total number of evens found.

## Requirements
1. Implement the solution in the provided starter file.
2. Print each even number on its own line, in ascending order:
   - 2, 4, 6, 8, 10
3. After the numbers, print the summary line:
   - `EVEN_COUNT=5`
4. Output must match the expected format exactly (no extra lines).

## Constraints
- Use a `for` loop and an `if` statement.
- Do not hardcode the output as a single multiline string.
