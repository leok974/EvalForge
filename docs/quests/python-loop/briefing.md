# Briefing — Loop

## Objective
Print all even numbers from 1 to 10 (inclusive), one per line, then print the final count.

## Where You’ll Work
- Edit: the quest’s starter file (contains `main()`).
- Validation: stdout is checked against a strict contract.

## Requirements
Expected output (exact):
2
4
6
8
10
EVEN_COUNT=5

## Constraints
- Use a `for` loop and an `if` conditional.
- Don’t hardcode the final output as one big string.

## Success Criteria
- Public validation passes (stdout matches exactly).
- Exit code is 0.
