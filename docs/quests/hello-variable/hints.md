# Hints — Hello Variable

## Hint 1 (nudge)
Define the variable exactly as required, then make sure your program actually uses it.

## Hint 2 (more specific)
If the grader checks stdout, you probably need to `print(message)`.

## Hint 3 (close)
Don’t forget the script entrypoint:
```py
if __name__ == "__main__":
    main()
```
