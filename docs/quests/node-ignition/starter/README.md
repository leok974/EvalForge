# Node Ignition

You are building a tiny CLI greeting program.

## Requirements
- Running `node index.js Leo` prints:
  `Hello, Leo!`
- Running `node index.js` prints a usage message to stderr and exits with code **2**:
  `Usage: node index.js <name>`

## Your tasks
1) Implement `greet(name)` in `src/greet.js`
2) Implement the CLI logic in `index.js`

## Notes
- Treat whitespace-only names as missing.
- Keep output formatting exact.
