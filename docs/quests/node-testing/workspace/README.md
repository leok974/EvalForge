# Testing with Node.js

Node.js has a built-in test runner.

## Objective
Implement assertions in `tests/math.test.js`.

## Requirements
1) Verify `add(2, 3)` equals `5`.
2) Verify `subtract(5, 2)` equals `3`.

## Running
- `npm test`
- or `node --test tests/math.test.js`

## Success Criteria
Both tests pass.
