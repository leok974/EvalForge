# Testing with Node.js

Node.js has a built-in test runner.

## Goal
Update `tests/math.test.js`:
1.  Implement the `add` test: `assert.equal(add(2, 3), 5)`
2.  Implement the `subtract` test: `assert.equal(subtract(5, 2), 3)`

## Running
Run `npm test` or `node --test tests/math.test.js`.
Both tests must PASS.
