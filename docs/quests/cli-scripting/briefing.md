# Briefing — Bash Scripting

## Objective
Write a script that handles arguments and validation.

## Success Criteria
1. `sh task.sh <name>`
   - Prints: `Hello, <name>!`
   - Exits: `0`
2. `sh task.sh` (or empty arg)
   - Prints: `Usage: task.sh <name>`
   - Exits: `1`

## Constraints
- Output must be exact (single line).
- No extraneous logging.
